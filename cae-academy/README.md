# CAE 虚拟仿真实训平台

一个**纯前端、零构建、全中文**的互动教学网站：在网页里模拟 **ANSYS Fluent**、**ANSYS Mechanical**、**Ansys Zemax OpticStudio** 三款软件的界面操作，用经典模型带初学者完整走通"从新建到出结果"的工作流。

> 硬性约束：双击 `CAE虚拟仿真实训平台-离线版.html` 就能跑。不需要 npm、不需要打包器、不需要本地服务器、不联网也能看。

---

## 一、怎么打开 / 怎么发给别人

| 方式 | 做法 | 特点 |
| --- | --- | --- |
| **离线单文件（推荐）** | 直接双击 `CAE虚拟仿真实训平台-离线版.html` | 所有 CSS/JS（含 three.js）都内联在这一个文件里，**文件内没有任何网络引用**，断网也能用 |
| 开发版 | 双击 `index.html` | 源码分文件，改完刷新即可；依赖同目录下的 `css/`、`js/`、`libs/` |
| 重新生成单文件 | 在仓库根目录执行 `node cae-academy/build.js` | 重新把 `index.html` + 本地资源打包成单文件版，并打印产物大小 |

**发给别人只发这一个文件就够了**（微信/邮件/网盘均可）：

- 单文件版不依赖文件夹里的任何其他东西——只把 `CAE虚拟仿真实训平台-离线版.html` 一个文件发过去即可。
- 如果打的是压缩包，请提醒对方**先解压再双击打开**（在压缩软件预览窗口里直接双击，浏览器拿不到临时解压的完整文件，是"传过去打不开"最常见的原因）。
- 文件自带**开机自诊断**：万一在对方浏览器里出了启动错误，页面底部会出现红条写明原因，不会再是无声的白屏。
- 浏览器要求：Chrome / Edge / Firefox / Safari 近两年版本（需要 WebGL；学习进度存在 localStorage，被禁用时自动降级为不记忆，不影响使用）。

## 二、三个模块

### 1. ANSYS Fluent —— 外流场 · 流体仿真（青绿 `#19b5a5`）

模型：**F1 方程式赛车外流场**

工作流：几何 → 计算域 → 网格 → 物理模型 → 边界条件 → 求解 → 收敛监控 → 后处理 → 气动力报告

看什么：残差曲线怎么收敛、边界层网格为什么要局部加密、压力云图上的低压区在哪里、
升力/阻力/下压力三个力分量怎么从积分里来。

### 2. ANSYS Mechanical —— 结构力学 · 有限元（橙 `#e8833a`）

模型：**稚晖君 Dummy 机械臂**

工作流：导入几何 → 材料 → 接触/连接 → 网格 → 约束与载荷 → 求解 → 总变形/等效应力 → 安全系数

看什么：接触与连接该怎么选、应力集中处为什么是尖角，以及两个专门章节：
- **网格无关性验证**（第 5 步）：同一载荷下把单元尺寸从 16mm 一路加密到 3mm，
  看着「单元数还在成倍涨、关键读数已经不动了」判定网格无关。
- **安全系数怎么读**（第 10 步）：FS ≥ 2 / 1~2 / <1 三档判据，以及 FS 跌破 1 之后
  为什么线性解直接作废（可以点「制造：载荷施加两次」当场把它压到 1 以下）。

### 3. Zemax OpticStudio —— 光学设计 · 几何光线追迹（紫蓝 `#7c6cf0`）

模型：**125-200mm F/5.7 长焦变焦镜头**（9 片 18 面、三组式、单移动组变焦）

工作流（共 12 步）：新建与三窗布局 → 系统选项（入瞳/波长/视场）→ 镜头数据编辑器
→ 玻璃目录与半口径 → 初始结构 → **3D 布局图** → 单光线追迹与一阶性质 → 点列图
→ **MTF 曲线** → 评价函数 → 优化 → 变焦复核

看什么：评价函数怎么把"看得清"翻译成一个标量（Operand / Weight / Target 每一列都真在算）、
Solve Type 怎么决定哪些面是自由度、变倍组空气间隙怎么靠二分法解出全焦段、
RMS 弥散半径和 MTF 曲线达标意味着什么、3D 布局图与镜头数据编辑器怎么对上号。

> 标称变焦行程 125–200mm。能不能真的走到 125 取决于处方：出厂的优化处方广角端约停在
> 130mm（单移动组的行程限制），点「恢复初始」回到骨架处方时能精确命中 125.00mm。
> 第 12 步会把两端实际读数打印到伪终端。

## 三、界面怎么用

```
┌──────────────────────────────────────────────────────────────┐
│ 品牌栏                                        视口操作提示     │
├──────────────────────────────────────────────────────────────┤
│ [Fluent] [Mechanical] [Zemax]        ← 模块标签页（带进度）    │
├───────────┬──────────────────────────────┬───────────────────┤
│  步骤导航  │        伪软件窗口             │     教学卡        │
│   240px   │  菜单栏 / 工具栏 / 树 / 属性   │      340px       │
│           │  3D 视口 / 伪终端 / 状态栏      │ 目标·操作·原理   │
│  ✓ 进度条 │                              │ 提示·上一步·下一步 │
└───────────┴──────────────────────────────┴───────────────────┘
```

- **左侧**：步骤列表，已完成的步骤打勾，下方是本模块的学习进度条（自动存 localStorage，刷新不丢）。
- **中间**：伪软件窗口。顶上是菜单栏与 ribbon 工具栏，左侧是模型树（Outline），右侧是属性面板，
  下面是 3D 视口和伪终端（求解器输出、残差、迭代日志都往这里写）。
- **右侧**：教学卡。包含 **本步目标 / 界面操作 / 物理原理 / 三维可视 / 预期结果** 五个小节。
- **提示是渐进式的**：默认只给出第 1 条，觉得卡住了就点 **「再给一条提示」**，一次放一条，
  不会一上来就把答案摊开。
- 快捷键：`Alt + →` 下一步，`Alt + ←` 上一步。
- 3D 视口：**左键拖动**旋转、**滚轮**缩放、**右键拖动**平移、触屏双指捏合缩放。

## 五、模块工程师怎么接入

1. 读 `js/app.js` **顶部的 CONTRACT 注释**——那是唯一的对接文档，与实现保持一致。
2. 只改自己那一个 `js/<模块>.js`，不要动 `app.js` / `three-setup.js` / `app.css` / `index.html`。
3. 在文件里 `CAE.registerModule({ id, name, tagline, accent, build })`。
4. `build(ctx)` 里搭伪软件界面（只用 `css/app.css` 共享类），调 `api.setViewport()` 建 3D 视口，
   再调 `api.setSteps()` 注册步骤。
5. 每个步骤的 `enter(ctx)` 负责"走到这一步时把画面摆好"，并且要**幂等**——
   因为切步骤、来回切标签页、刷新恢复进度都会重新调用它。

三条最容易踩的坑：

- **禁止 ES module**。全部经典 `<script>`，东西挂在 `window.CAE` 上，不许用 `import` / `export`。
- **`enter` 必须幂等**。第二次进来前先清掉上一步建的网格，否则会叠加成一坨。
- **不加载外部模型/贴图**。三维几何一律用 `THREE` 代码程序化生成。

## 六、建议的学习路径

1. **先摸一遍 Fluent**（约 40 分钟）。流体是三个模块里反馈最快的：改个参数、算几步、残差立刻动，
   适合建立"操作 → 结果"的因果直觉。
2. **再上 Mechanical**（约 50 分钟）。结构力学把"材料—几何—约束"三件事的作用放大到肉眼可见，
   重点体会网格无关性验证。
3. **最后啃 Zemax**（约 60 分钟）。光学设计是最抽象的：变量多、评价函数绕，
   但一旦把评价函数读懂了，前面两个模块的"优化"思路就都串起来了。
4. **回头看三份结果**：Fluent 的气动力报告、Mechanical 的安全系数、Zemax 的 MTF 曲线——
   这三个数字就是三个方向的工程判据。

> 学习进度按模块分别存在浏览器 localStorage（键 `cae-academy:progress:v1`）。
> 左上角「重置」按钮可以清空当前模块的进度。
